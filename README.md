# Latyan Dam Breach – HEC-RAS

HEC-RAS 2D simulation of a hypothetical dam-break flood at Latyan Dam, Iran, including terrain analysis, flood-wave propagation, inundation mapping, and visualization.

## Project Status

Early-stage setup. Terrain data, GIS layers, HEC-RAS model files, and simulation results will be added progressively.

## Study Area

Latyan Dam and the downstream Jajrood River corridor near Tehran, Iran.

## Main Objectives

- Prepare terrain and GIS data for HEC-RAS.
- Build a 2D hydraulic model.
- Define a hypothetical dam-breach scenario.
- Simulate downstream flood-wave propagation.
- Produce flood depth and velocity maps.
- Create clear visualizations and animations of the simulated flood.

## Important Note

This is an educational and research-oriented hypothetical dam-break simulation. Breach parameters and resulting inundation are model assumptions and must not be interpreted as an assessment or prediction of the actual safety of Latyan Dam.

## Planned Workflow

1. Terrain acquisition and preparation
2. GIS and study-area preparation
3. HEC-RAS 2D model setup
4. Hypothetical breach scenario definition
5. Hydraulic simulation
6. Flood-depth and velocity mapping
7. Visualization and analysis
8. Documentation of assumptions and limitations
